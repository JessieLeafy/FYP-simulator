# Project Context

This repository contains a Final Year Project on:

LLM-powered multi-agent negotiation simulation.

Agents negotiate prices through alternating-offer bargaining in simulated markets.

Experiments evaluate:

- concession curves
- anchoring effects
- deadline pressure
- market equilibrium
- shock response
- reputation dynamics
- communication strategies
- market mechanisms

# Paper Writing Rules

When editing the research paper:

Source of truth:
- CLAUDE.md
- README.md
- DESIGN.md
- EXPERIMENT_REPORT.md
- experiment scripts
- outputs/results
- papers folder

Writing rules:
- Do not invent results, metrics, or citations
- If uncertain about a detail, mark it [VERIFY]
- Prefer repository evidence over assumptions
- Avoid exaggerated novelty claims
- Write in academic conference style
- Maintain consistency with existing sections

Editing rules:
- Edit section files in paper/*.tex
- Do NOT edit main.tex unless explicitly instructed
- Sections must compile when included with \input{}
